Where to Find Your API Key
D-Tools SI: In the SI Control Panel, go to Start → Setup → Control Panel → Manage Integrations. Generate or copy the API key for your integration. Add it to each request using the header X-DTSI-ApiKey.
D-Tools Cloud: Go to Settings → Integration → Developer → API Keys inside D-Tools Cloud. Copy the key — it will be sent as the header X-API-Key with each request.
